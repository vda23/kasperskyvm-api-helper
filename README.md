# kasperskyvm-api-helper.sh

Интерактивный bash-скрипт для выгрузки данных из Kaspersky Vulnerability Management по API: активов, уязвимостей и ПО. Скрипт получает токен сессии в Kaspersky Security Center, перебирает все страницы ответа API и сохраняет каждый набор данных в один JSON-файл.

## Требования

- Наличие сетевого доступа до сервера(-ов) с установленными KSC (порт 13299) и Kaspersky VM (порт 5054).
- bash 4+, curl, стандартные утилиты Linux (coreutils, grep, sed, awk).
- python3 или jq — желательно, для склейки страниц. Если их нет, используется встроенный разбор ответа API.
- Учётная запись KSC с правами на чтение данных Kaspersky VM.

## Начало работы

```bash
chmod +x kasperskyvm-api-helper.sh
./kasperskyvm-api-helper.sh
```

Скрипт запросит:

1. FQDN устройства с Kaspersky Security Center;
2. имя пользователя KSC;
3. пароль (ввод скрыт);
4. FQDN устройства с Kaspersky VM. По умолчанию подставляется имя текущего сервера.

Порты 13299 и 5054 подставляются автоматически. Для нестандартной инсталляции их можно изменить в константах `KSC_PORT` и `KVM_PORT` в начале скрипта.

После входа откроется меню:

| Пункт | Данные | Метод API |
|---|---|---|
| 1 | Активы | `POST /v1/assets` |
| 2 | Уязвимости | `POST /v1/vulnerabilities/detections` |
| 3 | ПО | `POST /v1/software` |
| 4 | Всё указанное выше | три файла |
| 5 | Изменить подключение | |
| 0 | Выход | |

За один запуск можно сделать несколько выгрузок, все они идут в одной сессии KSC.

## Результат

Файлы сохраняются в папку, где лежит скрипт:

```
kasperskyvm_assets_2026-10-13_10-15-02.json
kasperskyvm_vulnerabilities_2026-10-13_10-15-02.json
kasperskyvm_software_2026-10-13_10-15-02.json
```

Формат файла:

```json
{
  "data": [ ... все записи ... ],
  "meta": {
    "type": "vulnerabilities",
    "source": "https://kvm.corp.local:5054/v1/vulnerabilities/detections",
    "exportedAt": "2026-10-13T07:15:02Z",
    "total": 49338,
    "count": 49338,
    "pages": 5
  }
}
```

`total` — число записей, которое сообщил сервер, `count` — сколько записей фактически сохранено. Страница из 10 000 уязвимостей весит около 100 МБ, поэтому заранее проверьте свободное место на диске.

## Запуск без меню

Подходит для cron и других сценариев автоматизации. Пароль передаётся в переменной окружения `KSC_PASSWORD`:

```bash
KSC_PASSWORD='***' ./kasperskyvm-api-helper.sh \
  --ksc ksc.corp.local --kvm kvm.corp.local -u admin -t all
```

| Параметр | Назначение |
|---|---|
| `--ksc FQDN` | FQDN Kaspersky Security Center |
| `--kvm FQDN` | FQDN Kaspersky VM |
| `-u`, `--user` | Пользователь KSC |
| `-t`, `--type` | `assets`, `vulnerabilities`, `software` или `all` |
| `-s`, `--page-size` | Записей на странице, от 1 до 10000 (по умолчанию 10000) |
| `-o`, `--output` | Папка для файлов (по умолчанию папка скрипта) |
| `--cacert FILE` | Включить проверку TLS-сертификатов |
| `--tls-help` | Пошаговая инструкция по включению проверки TLS |
| `--no-color` | Вывод без цветов |
| `-h`, `--help` | Справка |

## Безопасность

- Логин, пароль и токен хранятся только в памяти процесса и нигде не сохраняются.
- Пароль и токен передаются в curl через stdin, поэтому их не видно в списке процессов (`ps`).
- При выходе, в том числе по Ctrl+C, скрипт закрывает сессию KSC и удаляет временные файлы.
- По умолчанию проверка TLS-сертификатов выключена (аналог `curl -k`). Для рабочей среды рекомендуется её включить: подробности выводит `./kasperskyvm-api-helper.sh --tls-help`.

## Возможные ошибки

| Сообщение | Что проверить |
|---|---|
| `KSC отклонил вход (HTTP 401)` | Имя пользователя и пароль KSC |
| `Нет связи с KSC` / `Нет связи с Kaspersky VM` | FQDN, доступность портов 13299 и 5054, сертификат при `--cacert` |
| `Сессия KSC истекла` | Ничего: скрипт сам получит новый токен и продолжит выгрузку |
| `Сервер сообщил N записей…` | Данные изменились во время выгрузки (например, прошло сканирование). Повторите выгрузку. |
