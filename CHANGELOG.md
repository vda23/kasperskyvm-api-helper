# История изменений

## [1.0.0] — 2026-10-13

Первая версия.

- Интерактивное меню: выгрузка активов, уязвимостей и ПО из Kaspersky VM, по отдельности или всё сразу.
- Авторизация через сессию Kaspersky Security Center (`Session.StartSession`), заголовок `X-KSC-Session`.
- Автоматический перебор всех страниц API по `meta.pagination.total`, результат в одном JSON-файле.
- Ввод только FQDN, порты 13299 (KSC) и 5054 (Kaspersky VM) зашиты в скрипт.
- Режим без меню для автоматизации (`-t`, пароль в `KSC_PASSWORD`).
- Опциональная проверка TLS-сертификатов (`--cacert`) и пошаговая инструкция (`--tls-help`).
- Учётные данные не сохраняются на диск и не видны в списке процессов; сессия KSC закрывается при выходе.
